# Singapore Math Gym

A single-page maths practice site for the Singapore MOE syllabus, P1–P6. It covers high-ability and Olympiad topics, bar models, self-learning and self-testing, and an optional timed mock exam.

Everything is in `index.html`, with no build step. Progress is saved in the browser's localStorage.

## Deploy
- **GitHub Pages:** Settings → Pages → Deploy from branch → `main` / root.
- **Netlify:** import this repo (no build command, publish directory `/`), or drag `index.html` into Netlify Drop.
- **Locally:** open `index.html` in any browser.
